日期：2026-11-20。状态：本地验收通过，尚未发布；未访问或修改生产数据库。

## 实现与发布范围

- 客户默认显示最近一次完整数据、实际覆盖日期和所选数据的更新时间；仅一个账户时自动选择，自定义日期按需展开。
- 四张指标卡由完整覆盖的广告系列报表优先汇总；没有可用系列数据时才使用完整每日数据，二者不叠加。点击率为总点击/总展示，真实零正常显示，缺失与零分母显示“—”。
- 五国按真实系列 ID 映射为阿联酋、澳大利亚、越南、巴西、墨西哥。映射仅用于已核实账户，不根据名称猜测其他账户。客户默认不显示原始 ID 和英文名称。
- 详情与数据说明折叠；只有真实每日数据才显示趋势。手机指标两列、表格横向滚动。
- 更新数据→选择 CSV→自动识别并预览→确认更新→返回刚更新的数据。仅缺少必要字段时要求补充；字段映射及完整范围模式在高级选项。
- 保留服务端账户授权、管理员导入限制、费用过滤、签名预览、事务提交、修订覆盖、去重及审计。

源码：`admin-ads.html`、`admin-ads.css`、`admin-ads-csv.js`、`admin-ads-import.html`、`admin-ads-import.js`、`server/ads-csv.js`、`server/ads-dashboard.js`、`api/ads-data.js`。

实际发布包将最后一个 API 文件映射为 `server/ads-data-handler.js`，继续复用现有 analytics-query 路由，保持 12 个函数。不得额外发布为第 13 个函数。清单：`docs/ads-csv-simplified-review-package.json`。

## 保留限制

- 区间汇总只用于实际完整覆盖范围，不能拆分成某天数据。不同区间重叠或区间/每日粒度冲突仍按现有事务规则拒绝，要求提供明确的可兼容报表；不自动删除已有数据。
- 自动识别不等于支持所有 Google Ads 导出变体；真实验证样本是本次五国系列文件，其他格式另有合成回归覆盖。
